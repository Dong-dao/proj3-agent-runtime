# S2 机制设计说明 ①：COW 上下文共享前缀与引用计数

> 交付人：董博文（T1 机制设计）　日期：2026-11-25　落盘路径：`docs/design/S2-01-COW上下文设计.md`
> 对应 S2 逐日：11/24 共享前缀 + 引用计数、11/25 分支写入触发复制。

---

## 1. 题面痛点与 OS 出处

**痛点**：多 Agent 共享同一份系统提示词与上下文前缀时，朴素实现给每个 Agent 复制一份完整对象，内存与拷贝开销随 Agent 数线性增长。

**OS 出处**：`fork()` 的写时复制（COW）与页表只读标记——父进程 fork 后父子共享同一组物理页，仅在任一方写入时触发缺页中断、复制该页。我们迁移的是「不可变共享 + 写入才复制」这条思想，不是页表实现。

## 2. 机制定义

- **不可变前缀**：`acquire(agent_id, prefix_id)` 把共享前缀登记为一个对象，多个 Agent 通过 `refs` 共享同一对象，不各自持有副本。
- **引用计数**：`refs` 恒等于持有者集合 `holders` 的大小；`acquire` +1，`release` −1，归零才真正释放对象。
- **写入触发复制**：`write(agent_id, ctx_id, data)` 时，若 `refs > 1`，构造新对象、写入新数据、调用方引用迁移到新对象、旧对象 `refs −1`；若 `refs == 1`，独占写入无需复制（本 S2 实现统一构造新对象以便计数，语义上等价于「无共享则无额外拷贝代价」）。

## 3. 触发条件（可判定、可测）

```text
写入且 refs > 1  →  复制：copy_count += 1，copy_bytes += len(data)
写入且 refs == 1 →  不复制：两个计数均不变
释放后 refs == 0 →  对象从表中移除
```

判定点唯一：`ContextStore.write()` 的写入复制分支（契约②第 4 节已定名）。这一条是验收的关键——不能把「每次 write 都 +1」当成 COW。

## 4. 状态不变量

| 编号 | 不变量 | 由哪段代码保证 | 怎么测 |
|---|---|---|---|
| C1 | `refs == len(holders)` 恒成立 | `acquire` / `_release_ref` 成对修改两个结构 | 多次 acquire/release 后断言两者相等 |
| C2 | `refs > 1` 时写入必复制，计数 +1 | `write()` 复制分支 | 两 Agent 共享后写入，断言 `copy_count` 从 0 变 1、`copy_bytes` 增加 len(data) |
| C3 | `refs == 1` 时写入不增加拷贝计数 | `write()` 独占分支 | 单 Agent 持有写入，断言两个拷贝计数不变 |
| C4 | `refs == 0` 对象才释放 | `_release_ref` 归零分支 | 释放最后一个持有者，断言对象从 `_objects` 移除 |
| C5 | 非持有者读写被拒 | `read` / `write` 的 `holders` 校验 | 未持有者读/写，断言抛 `E_PERM` |

## 5. 可数证据（对接七项指标）

| 证据 | 指标字段 | 采集位置 | S2 验收期望 |
|---|---|---|---|
| 共享命中 | `share_hit_rate`（诊断量） | `ContextStore.stats()` | 两 Agent 共享同一前缀时 > 0 |
| 拷贝次数 | `copy_count` | `write()` 复制分支 | 共享写入 1 次 → +1 |
| 拷贝字节 | `copy_bytes` | 同上 | 等于被复制对象字节长度之和 |
| 峰值内存 | `peak_rss_mb` | 采样线程 `resource.getrusage` | S3 全量对比用，S2 只验证能采到 |

## 6. 与 T2 实现的对接点

T2 已落地 `runtime/context.py`：`acquire/read/write/release/_release_ref/stats()` 六个方法，S1 stub 在 `write()` 里留了「S2 COW 实现后启用」注释、`stats()` 三个计数恒为 0。**S2 实现只填这两处内部逻辑，不改契约①第 4 节任何签名**。域标签 `domain_tag` 字段已在对象结构里，隔离域机制（说明 ②）直接复用，不新增结构。

## 7. 用户态边界声明（答辩防守）

| 作品里的机制 | OS 原型 | 必须如实声明的边界 |
|---|---|---|
| COW 上下文 | 页表级写时复制 | **逻辑 COW，不是页表级**；不接 KV Cache、不省显存，省的是 Python 对象拷贝 |
