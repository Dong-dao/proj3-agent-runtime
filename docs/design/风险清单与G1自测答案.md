## 五、S1 自测题答案要点（周日互讲随机抽，4/5 过关）

| # | 题目 | 过关答案要点 |
| --- | --- | --- |
| 1 | 动态生成子任务时如何避免死锁 | 依赖图环检测 + 子任务继承父任务优先级与配额；`spawn()` 后重测环，有环拒绝入图 |
| 2 | 题面参考 CFS，我们为什么谈 EEVDF | openEuler 24.03 LTS 基于 6.6 内核已用 EEVDF；迁移的是公平份额与时延约束思想，不是照抄 vruntime；把 vd 引入依赖图是创新点 |
| 3 | 状态机为什么要有唯一转换入口 | 保证不变量集中可验证，避免分散赋值导致非法状态；所有状态变更经 `transition()`，非法转换拒绝并记日志 |
| 4 | 统一 Resource Handle 解决题面哪个痛点 | 模型 / 工具 / 系统资源缺统一抽象；对应 fd + 权限位，越权必拒、终止必回收 |
| 5 | 为什么先做 FIFO 基线 | 没有基线就无法证明调度机制带来多少收益，性能 20 分无依据；S1 用 stub 先跑通，S3 全量三基线 |
