# proj3-agent-runtime

2026 年操作系统中西部与华南区域赛 **proj3《面向多智能体的操作系统级执行时（Agent Runtime）》** 参赛仓库（难度 A）。

队伍：海南大学 · 董博文、陈苗苗、栾诗童（3 人）

## 一句话定位

用户态 Agent Runtime 机制验证：把 Agent 当进程管、把上下文当内存管、把模型与工具当文件管，每一种管法都留下「状态不变量 + 可数的数字 + 一组基线对照」。不套现成框架、不接真实大模型做性能数据、不改内核。
